# ABRIS 系统设计文档

## 项目概览

ABRIS（AI Bioinformatics Research Intelligence System）是一个基于 OpenCode 内核的生物信息学全自动 AI 研究系统。系统通过多 Agent 长链推理和多模型协同编排，实现从文献检索、数据分析、代码执行到成果审阅的端到端自动化科研流水线。

- 开源仓库：https://github.com/Linxira-OS/extendai-lab-Studio
- 开源协议：GNU AGPL-3.0
- 项目性质：课题组核心研究工具，生物信息学全自动分析平台

## 核心痛点

生物信息学分析链条极长，从文献检索、数据清洗、工具选型、代码编写、参数调优、结果验证到成果撰写，需要跨越多个专业领域。传统模式下研究者需手动切换数十种工具和数据库，上下文极易断裂。现有单模型方案存在三大瓶颈：

1. 无法同时满足百万级长上下文推理、多模态图表理解、大规模并行搜索和低成本执行的需求
2. 生信分析中大量文献以 PDF 图表形式呈现关键数据，需要真正的多模态理解而非纯文本阅读
3. 自动化科研需要长链推理能力以保持跨步骤一致性，单模型在处理复杂生信流水线时容易在中间步骤偏离目标

## 核心逻辑流

系统采用多 Agent 长链推理架构，各 Agent 通过统一上下文总线传递中间结果，形成推理-执行-审阅-反馈闭环。

### 长链推理层

由 DS V4 Pro 担任总指挥，负责将复杂生信任务拆解为有序步骤并持续推理。任务从高层目标出发，逐级分解为可执行的原子操作，每个步骤的产出作为下一步骤的上下文输入，确保全链条一致性。

### 多 Agent 协作层

| Agent | 角色 | 职责 |
|-------|------|------|
| DS V4 Pro | 总指挥 / 代码执行 | 任务拆解、流水线编排、代码生成、持续推理 |
| 小米 MiMo 2.5 Pro | 快速审阅 / 调度 | 审阅 DS Pro 产出、指挥下一步工作、任务再调度 |
| 小米 MiMo 2.5 标准版 | 多模态文献分析 | 文献阅读整理、图表识别、结构化数据提取 |
| DS V4 Flash | 并行搜索 / 工具调用 | paper search、学术搜索、网络资源查找、基础工具调用 |
| Gemma 4 27B（本地） | 视觉外挂 | 为 DS Pro 提供图像辅助理解，弥补其无原生多模态短板 |
| Gemini 3.1 Flash/Pro | 谷歌学术补充 | 补充国内学术搜索盲区，Flash 主力 Pro 备援 |
| GPT 5.4 | 终审 | 最终成果审阅，独立质量保证 |

### 协作流程

总指挥（DS Pro）拆解任务 → 调度员（小米 2.5 Pro）审阅并分派子任务 → 执行层（DS Flash 搜索、小米标准版读文献、Gemma 看图）并行执行 → 结果汇总 → 调度员审阅 → 总指挥根据反馈迭代 → 终审（GPT 5.4）独立评估最终产出

## 系统架构

ABRIS 采用六层架构设计：

| 层级 | 功能 |
|------|------|
| Layer 0 | 环境适配与文件安全 |
| Layer 1 | 原子技能注册与管理 |
| Layer 2 | 分析流水线编排 |
| Layer 3 | 多模型协同调度 |
| Layer 4 | 数据循环与知识积累 |
| Layer 5 | 智能科研发现 |

## 多模型协同策略

### 主模型层

| 模型 | 角色 | 选用理由 |
|------|------|----------|
| DS V4 Pro | 主代码执行器 & 总指挥 | 100 万上下文、编程能力极强，参数规模充足，是整个系统的核心推理引擎。不具备原生多模态能力，通过外挂本地 Gemma 4 27B 实现视觉理解 |
| 小米 MiMo 2.5 Pro | 快速审阅 & 任务调度 | 经济性好，支持 TTS，快速审阅 DS Pro 产出的内容并指挥下一步工作，反馈速度快 |

### 执行与辅助层

| 模型 | 角色 | 选用理由 |
|------|------|----------|
| 小米 MiMo 2.5 标准版 | 文献整理与分析 | 具备原生多模态能力（图片识别），经济性好，适合大量文献的阅读、整理和结构化，配合自制图片抽取工具对文献中的图表进行严谨识别 |
| DS V4 Flash | 网络搜索 & 工具调用 | 承担大量基础搜索任务（paper search、学术搜索、网络资源查找），辅助两个主模型高效运作 |

### 外部学术补充

| 模型 | 角色 | 选用理由 |
|------|------|----------|
| Gemini 3.1 Flash（主力）/ 3.1 Pro（备援） | 谷歌学术补充 | 对接谷歌学术资源，提供更全面的学术内容获取渠道。日常使用 Flash 模型，当 Flash 出现不稳定或结果不准确时切换 Pro 进行修正 |

### 本地视觉辅助

| 模型 | 角色 | 选用理由 |
|------|------|----------|
| Gemma 4 27B（本地部署） | 外挂视觉理解 | DS V4 Pro 不具备原生多模态能力，本地部署 Gemma 4 27B 作为外挂视觉模块，为 DS Pro 提供图像辅助理解能力，确保返回给主模型的视觉内容是准确的 |

### 终审层

| 模型 | 角色 | 选用理由 |
|------|------|----------|
| GPT 5.4 | 最终成果审阅 | 100 万上下文窗口，参数量大，学术资源与开源项目生态成熟，作为最终质量保证环节最为稳定可靠。GPT 5.5 虽更智能，但疑似为重新训练版本，在知识一致性和稳定性方面尚不及 5.4，且我们尚未完成对 5.5 的提示词适配和功能适配工作，因此暂不采用 |

## 模型选择逻辑

我们在模型选型上经过了市场的详细对比与实测：

多模态需求方面，国内真正支持多模态（特别是图片识别）的服务商仅 QWen 和 Kimi，但 QWen 上下文效率不足且价格较高，Kimi 上下文长度不够且额度少。小米 MiMo 2.5 标准版自带原生多模态能力，在图片识别场景下经济性极佳。DS V4 Pro 不具备原生多模态，因此我们通过本地部署 Gemma 4 27B 作为外挂视觉模块来弥补这一短板。

编程能力方面，GLM 编程能力尚可但上下文严重不足，无法满足生物信息学长流程分析需求。

经济性方面，MiniMax 模型能力不足，不适合科研系统使用。

B站直播和实时互动场景需要极高上下文和快速响应，小米 MiMo 模型的经济性在此类场景下表现优秀。

最终方案：DS V4 Pro（代码执行+总指挥）+ 小米 MiMo 2.5 Pro（快速审阅+调度）+ 小米 MiMo 2.5 标准版（多模态文献分析）三核驱动，辅以 DS V4 Flash 做大规模基础搜索、GPT 5.4 做终审、Gemma 4 27B 本地做视觉辅助（弥补 DS 无原生多模态的短板）、Gemini 3.1 Flash/Pro 做谷歌学术补充，形成经济高效、能力互补的完整模型矩阵。

## 相关开源项目

### OpenAgent Labforge —— 系统运行时基础框架

为 ABRIS 提供 OpenCode 内核集成与插件化扩展能力。

仓库：https://github.com/BOHUYESHAN-APB/openagent-labforge

### bioSkills —— 生物信息学技能库

预置了大量生物信息学相关的 SKILLS.md 和代码示例，专为 AI 驱动的科研分析设计。提供分析技能库、流水线模板、工具适配和代码生成指导。

仓库：https://github.com/BOHUYESHAN-APB/bioSkills

### N-T-AI —— 早期 AI 实时互动项目

早期的类 Neuro-sama AI 虚拟主播项目，已在 B站进行开发者直播。技术栈为 Python 后端。积累了实时交互、上下文管理、工具调用等基础工程经验。局限在于 Omni 模型适配不理想、上下文容易膨胀、工具链不够清晰、Python 运行时效率不足。

仓库：https://github.com/BOHUYESHAN-APB/N-T-AI

### CMYKE —— ABRIS 人性化交互层 / N-T-AI 的 Rust 重构迭代版

使用 Rust 完全重构后端，在运行时效率、上下文管理和工具链明确性上大幅提升。Omni 模型高效适配，Minecraft 模组控制 AI 自由探索与游玩，B站直播。同时作为 ABRIS 系统的人性化交互层，面向不熟悉专业交互界面的用户群体。

仓库：https://github.com/BOHUYESHAN-APB/CMYKE

## 技术亮点

1. 全自动生物信息学分析：系统既能完成人工部署的任务，也可以自主寻找内容进行完善
2. 多 Agent 长链推理：总指挥拆解任务，多 Agent 并行执行，终审独立把关
3. 文献深度理解：自制图片抽取工具，将文献中的图表单独提取并返还模型进行严谨解读
4. 百万级上下文：DS V4 Pro 和 GPT 5.4 均提供 100 万 token 上下文窗口，满足长流程分析需求
5. 经济高效：小米 MiMo 模型在实时交流和快速审阅场景下性价比极高

## 适用场景

生物信息学自动化分析流水线、基因组学与转录组学数据处理、文献综述自动化撰写、科研发现辅助与假设验证、AI 辅助代码生成与优化。
